### Project 2: Iris Flower Classification Using KNN

An end-to-end supervised machine-learning project that classifies Iris flowers using K-Nearest Neighbors, feature scaling, cross-validation, and model evaluation.

**Results:**

- Best K value: 5
- Cross-validation accuracy: 96.67%
- Test accuracy: 93.33%
- Macro F1-score: 0.9327
